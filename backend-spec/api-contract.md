# API contract

Single source of truth for request/response shapes. Task names here MUST
match the datasets actually chosen in `data/TODO_sources_licensing.md`
(ESOL/AqSolDB, Tox21, ClinTox, BBBP) — not the illustrative placeholder
names ("Hepatotoxicity", "CYP inhibition") used earlier in the TODO
brainstorm, which are not in scope unless `TODO_sources_licensing.md`'s
CYP450 P2 item is later picked up.

## `POST /admet-profile`

### Request
```json
{ "smiles": "CC(=O)Oc1ccccc1C(=O)O" }
```

### Response — 200 OK
```json
{
  "id": "b3f1c2a0-...",
  "smiles": "CC(=O)Oc1ccccc1C(=O)O",
  "disclaimer": "Research/educational use only. Not for clinical or regulatory decision-making.",
  "model_version": "0.1.0",
  "applicability_domain": { "in_domain": true, "distance_score": 0.31 },
  "profile": {
    "solubility": { "value": -2.31, "unit": "logS", "confidence": 0.82 },
    "bbb_penetration": { "probability": 0.74, "confidence": 0.68 },
    "toxicity_tox21": {
      "aggregate_risk": 0.22,
      "confidence": 0.71,
      "panel": {
        "NR-AR": 0.05, "NR-AR-LBD": 0.03, "NR-AhR": 0.41, "NR-Aromatase": 0.08,
        "NR-ER": 0.12, "NR-ER-LBD": 0.09, "NR-PPAR-gamma": 0.02,
        "SR-ARE": 0.33, "SR-ATAD5": 0.06, "SR-HSE": 0.11, "SR-MMP": 0.44, "SR-p53": 0.07
      }
    },
    "clinical_trial_toxicity": { "probability": 0.15, "confidence": 0.65 },
    "fda_approval_likelihood": { "probability": 0.58, "confidence": 0.60 }
  }
}
```

| Field | Type | Notes |
|---|---|---|
| `id` | string (UUID) | server-generated, persisted so `GET /admet-profile/{id}` and comparison-page shareable links work; the frontend never generates this itself |
| `smiles` | string | canonicalized echo of input |
| `disclaimer` | string | always present, fixed research-use text — see `frontend-spec/app-shell.md` for where it's shown in UI |
| `model_version` | string | for traceability |
| `applicability_domain.in_domain` | bool | drives the "out-of-domain" UX in `frontend-spec/predict-page.md` |
| `applicability_domain.distance_score` | float | raw distance metric (descriptor-based), not shown directly to users, only the derived badge |
| `profile.solubility` | object | regression (ESOL/AqSolDB); `value` is predicted logS, not a 0–1 probability |
| `profile.bbb_penetration` | object | classification probability (BBBP) |
| `profile.toxicity_tox21` | object | `aggregate_risk` = max of the 12 panel probabilities (worst-case framing, since any single positive assay is a real flag — averaging would hide it); `panel` = full breakdown, all 12 Tox21 assay codes |
| `profile.clinical_trial_toxicity` | object | ClinTox `CT_TOX` task |
| `profile.fda_approval_likelihood` | object | ClinTox `FDA_APPROVED` task |
| `confidence` (nested, per task) | float 0–1 | from calibration/uncertainty pipeline (`ml/TODO_calibration_uncertainty.md`); never omitted — unlike project #1's baseline, this project's core value prop IS calibrated uncertainty, so P0 not P2 |

### Response — 422 (invalid SMILES)
```json
{ "detail": "Could not parse this SMILES string" }
```

## `GET /admet-profile/{id}`
Same response shape as above, for a previously computed and stored profile (used by the comparison page and shareable result links).

## `GET /health`
```json
{ "status": "ok", "model_loaded": true, "db_connected": true }
```

### Залежності
- `profile` keys and the Tox21 `panel` assay codes are generated by the
  training pipeline in `ml/TODO_experiments_multitask.md` /
  `ml/TODO_calibration_uncertainty.md` — if the dataset selection in
  `data/TODO_sources_licensing.md` changes, update this file first.
- Consumed by `frontend-spec/predict-page.md` (radar + cards),
  `frontend-spec/data-visualization.md` (radar axes, Tox21 panel expansion).
