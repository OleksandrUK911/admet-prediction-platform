# App shell

```
┌────────────────────────────────────────────────────┐
│ ⚠ Research/educational use only — not for clinical  │  ← постійний банер, не закривається
│   or regulatory decision-making.                    │
├────────────────────────────────────────────────────┤
│  Logo   Predict   Compare   About          [🌐 EN]   │  ← header
├────────────────────────────────────────────────────┤
│                                                      │
│                   (сторінка)                        │
│                                                      │
└────────────────────────────────────────────────────┘
```

- Дисклеймер-банер — окремий рядок над header, фіксований колір `warning`
  (див. [design-system.md](design-system.md)), присутній на кожній сторінці,
  без кнопки закриття (на відміну від типового dismissible banner — це
  свідоме рішення, узгоджене з `TODO_ui_components.md`: попередження про
  research-use має бути постійно видимим).
- Header: 3 пункти навігації (Predict / Compare / About), активний
  підсвічений.
- Footer (у `TODO_dashboard_layout.md`) — додатково короткий текстовий
  лінк на дисклеймер, для видимості навіть при скролі великого дашборду.

## Стани
- **Error boundary:** контент під header замінюється на "Something went
  wrong" + Reload. Банер дисклеймера й header лишаються видимими завжди —
  навіть при краші сторінки попередження не повинно зникати.
