# Comparison page

Шлях `/compare`. Порівняння 2–3 молекул side-by-side (обмеження: максимум 3
— більше ускладнює зчитування радар-графіків накладених один на одного).

## Layout

```
┌──────────────────────────────────────────────────────────┐
│  [SMILES input #1]  [SMILES input #2]  [+ Add molecule]    │
│  (максимум 3 інпути; "+ Add" ховається після третього)     │
├──────────────────────────────────────────────────────────┤
│         Overlaid radar (до 3 профілів, різні кольори)       │
│         Легенда: колір → SMILES/назва молекули               │
├──────────────────────────────────────────────────────────┤
│  Таблиця відмінностей:                                     │
│  | Endpoint          | Mol 1 | Mol 2 | Mol 3 | Найбільша різниця |
│  | Solubility        | -2.3  | -4.1  | -1.8  | Mol2 vs Mol3: 2.3 |
│  | BBB Penetration   | 0.74  | 0.12  | 0.68  | ...               |
│  | ...                                                            |
└──────────────────────────────────────────────────────────┘
```

- Оверлей-радар: до 3 напівпрозорих полігонів різного кольору (див. палітру
  в [design-system.md](design-system.md#порівняння-кольори)), без confidence
  band на оверлеї (занадто шумно) — invisible details доступні через клік на
  конкретну молекулу → відкриває її повну `AdmetResultCard`-панель нижче.
- Таблиця відмінностей: клітинка з найбільшим розкидом між молекулами
  візуально виділена (bold + іконка), а не просто числа поруд — це і є
  "візуальне виділення відмінностей", раніше лише назване завданням у
  `TODO_data_visualization.md`.

## Стани
| Стан | Що видно |
|---|---|
| 0–1 молекула введена | Радар не рендериться, показується placeholder "Add at least 2 molecules to compare" |
| 2–3 молекули, Loading | Кожен інпут окремо показує свій spinner (запити паралельні, не послідовні) |
| 2–3 молекули, Success | Оверлей-радар + таблиця |
| Одна з молекул — invalid/error | Її колонка в таблиці показує "—" з іконкою помилки, решта молекул рендериться нормально (часткова відмова, не блокує все порівняння) |
